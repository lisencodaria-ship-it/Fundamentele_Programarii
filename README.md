# Proiect Universitar - Fundamentele Programării

## Descriere
Acest proiect conține rezolvările pentru lucrările de laborator la disciplina Fundamentele Programării, realizate în limbajul C.

## Tehnologii utilizate
* Limbajul C
* Mediu de compilare: Programiz / GCC

## Structura proiectului
* `ex1.c` - Conversie de temperatură (Celsius în Fahrenheit)
* `ex2.c` - Calculator simplu realizat cu instrucțiunea switch
* `ex3.c` - Prelucrarea cifrelor unui număr și verificare număr prim
* `ex4.c` - Statistica notelor unei grupe (tablouri unidimensionale)
* `ex5.c` - Ordonare cu funcții și pointeri

## Instrucțiuni de rulare
1. Deschideți fișierul dorit într-un compilator C.
2. Compilați și rulați codul (Run).
3. Introduceți datele solicitate de la tastatură.
